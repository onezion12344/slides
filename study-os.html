How it works

As simple as opening an app

No complex setup. No learning curve. Just open it and start studying.

// Your daily workflow

const morning = await studyOS.capture({
  source: "PHIL1068 lecture",
  mode: "auto"
});

const notes = await studyOS.process(morning);
// → structured markdown + concept map

const session = await studyOS.practice(notes);
// → AI quiz, dialogue, Socratic Q&A

const report = studyOS.evaluate(session);
// → weak spots identified: 2 topics

studyOS.schedule(report.gaps, 2); // days

Five steps. One API.

Every function in Study OS connects to the next. No manual handoffs, no exporting/importing between tools.

● capture() — Screen, PDF, web, voice
● process() — LLM summarization + graph
● practice() — Active recall engine
● evaluate() — Gap analysis
● schedule() — Spaced repetition
