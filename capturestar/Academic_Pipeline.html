Each stage feeds the next. No dead ends. No manual handoffs.

STEP 01

Capture

Every piece of knowledge enters the system once. Never copy-paste between apps.

  • Screen recording + audio → Screenpipe 24/7
  • Lecture slides → PDF extraction (pymupdf)
  • Web research → Exa / Perplexity / WebFetch
  • WhatsApp / WeChat → chatlog_alpha
  • Voice thoughts → MiMo TTS/STT pipeline
📚

Input Sources

Screen, voice, PDF, web, chat — everything funnels into a single structured memory layer.

capture() → memory/ → process()
STEP 02

Process

Raw input becomes structured knowledge. LLM does the heavy lifting.

  • Lecture → Markdown notes (NeoVim + LuaSnip)
  • Paper → argument map (CLAPS / LARA framework)
  • Video → structured summary (onezion-video-summarize)
  • Concept → ontology graph (knowledge-base skill)
🧠

Knowledge Engine

Not just note-taking — building a structured, queryable knowledge graph that connects concepts across courses.

raw_input → LLM → structured_notes → graph
STEP 03

Practice

Knowledge without practice is fiction. AI-powered active recall.

  • DSE Oral → ElevenLabs ConvAI (3 modes)
  • DSE Listening → MiMo TTS batch generation
  • Logic/Philosophy → Grill-Me Socratic questioning
  • Coding → ChatLab conversation analysis
💬

Active Recall Engine

LLM as practice partner. Not passive reading — dialogue, quiz, debate. The 23% utilization gap closes here.

notes → generate_questions → user_reply → feedback
STEP 04

Evaluate

Measure what matters. Data-driven learning, not gut feeling.

  • ChatLab → sycophancy detection + LARA benchmark
  • Superforecasting → calibration tracking
  • Rize.io → time allocation analysis
  • Memory → cross-session knowledge retention
📊

Feedback Loop

Every practice session generates data. The system learns what you know, what you don't, and where you're overconfident.

session_data → analysis → weak_spots → adjust()
STEP 05

Iterate

The loop closes. Weak spots become next session's focus. Knowledge compounds.

  • Spaced repetition → automations (cron)
  • Memory hygiene → distill + prune old notes
  • Self-improvement → error pattern tracking
  • Darwin skill → auto-optimize workflows
🔁

Compound Learning

Each cycle makes the next one faster. The system gets smarter about you — your patterns, your gaps, your style.

evaluate() → identify_gaps → focus_next → evaluate()
